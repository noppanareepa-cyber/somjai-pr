# ระบบขอคิวรถคลังสินค้า — สมใจ

เว็บแอปบน Google Apps Script สำหรับขอคิวรถคลังไปส่งของให้ลูกค้า (กทม. + ปริมณฑล)
การตัดสินใจทั้งหมดอยู่ใน [`DESIGN.md`](DESIGN.md)

## ส่วนที่ทำแล้ว (เฟส 1 — พอสำหรับทดลองกับสาขาสายสี่)

- **หน้าขอคิว** (ไม่ต้องล็อกอิน): เลือกชื่อครั้งเดียว · วางลิงก์ Google Maps → ระบบหาระยะทางขับรถจากสาขา จังหวัด และค่าส่งตาม MEMO COO009/69 · ปฏิทินแสดงเฉพาะรอบที่รถผ่านสาขาพร้อมจุดที่เหลือ · ตัดรอบ 16:00 น. · ปลายทางต่างจังหวัดไม่รับ · เก็บค่าส่งต่ำกว่านโยบายต้องใส่เหตุผล · นอกรอบ/ด่วน
- **คำขอของสาขา**: ดูสถานะ เหตุผลที่ย้ายวัน ยกเลิกเองได้ก่อนคลังยืนยัน · เพิ่มชื่อตัวเองได้
- **คลัง** (PIN): ยืนยัน · ย้ายวัน/รถ · ยกเลิก · ส่งไม่สำเร็จ · แก้ค่าส่ง/TR · งานที่ต้องจัดใหม่เมื่อตารางรอบรถเปลี่ยน · งานเลยวันที่ยังไม่ปิด · ตรวจชื่อพนักงานใหม่
- **ใบงานรายวัน**: A4 หนึ่งแผ่นต่อคัน มี QR แผนที่ทุกจุด ค่าส่งที่ต้องเก็บ ช่องลูกค้าเซ็น · QR เปิดใบงานบนมือถือคนขับ (อ่านอย่างเดียว) · ปุ่มปิดรอบ
- **อนุมัติ** (ยอด < 3,000 นอกเส้นทาง): ผจก.เขต → CEO และ คลัง → COO ทำพร้อมกัน · อนุมัติไม่ครบภายใน 16:00 น. วันก่อนส่ง → เลื่อนรอบอัตโนมัติ
- **ประวัติการแก้ไข**: ทุกการกระทำบันทึกว่าใครทำ เมื่อไร

## ยังไม่ทำ (เฟสถัดไป)

- ขอรอบรถคลังของสาขา (แจ้งของส่งเข้า/รับคืน/ฝาก และขอรอบพิเศษ)
- ย้ายประวัติจากชีต "ตารางขอรอบรถโกดัง"
- รายงานรายเดือน (ค่าส่งเทียบนโยบาย แยกสาขา/พนักงานขาย)
- หน้าแก้ตารางรอบรถบนเว็บ (ตอนนี้แก้ในชีต "ตารางรอบรถ")

## ติดตั้งในบัญชี monpriya@somjai.co.th

ทำทั้งหมดขณะล็อกอินบัญชี **monpriya@somjai.co.th** — ชีตข้อมูลและสคริปต์จะเป็นของบัญชีนี้ และเว็บแอปจะทำงานในนามบัญชีนี้

1. **สร้างชีตใหม่** ใน Google Drive ของบัญชีนี้ ตั้งชื่อเช่น `ระบบขอคิวรถ (ฐานข้อมูล)` — ห้ามใช้ชีตเดิม "ตารางขอรอบรถโกดัง"
2. ในชีต: **ส่วนขยาย → Apps Script**
3. เปิดไฟล์ [`dist/Code.gs`](dist/Code.gs) (รวมโค้ดทั้งหมดไว้ไฟล์เดียว) → คัดลอก**ทั้งไฟล์** → วาง**ทับ**ของเดิมใน `Code.gs` → บันทึก (Ctrl+S)
   - ตั้งค่าโปรเจกต์ (⚙) → เขตเวลา: **(GMT+07:00) Bangkok**
   - (ทางเลือกสำหรับนักพัฒนา: ใช้ [clasp](https://github.com/google/clasp) `push` จากโฟลเดอร์ `apps-script/` ซึ่งแยกไฟล์ไว้)
4. เลือกฟังก์ชัน **`setup`** → เรียกใช้ → อนุญาตสิทธิ์ — ระบบสร้างชีตทั้งหมดพร้อมข้อมูลตั้งต้น (สาขา 34 แห่ง เขต รถ ตารางรอบรถ รายชื่อพนักงานจากข้อมูลเก่า) และตั้งเวลาเลื่อนงานอัตโนมัติ
5. **ตั้ง PIN**: ใน `Code.gs` ค้นหา `function setPins` (Ctrl+F) → ใส่ PIN (ตัวเลข ≥ 6 หลัก) ในฟังก์ชัน `setPins` → เรียกใช้ `setPins` → **ลบตัวเลขออกจากโค้ดแล้วบันทึก**
6. **เติมพิกัดสาขา**: กลับไปที่ชีต รีเฟรช → เมนู **ระบบขอคิวรถ → เติมพิกัดสาขาจากลิงก์แผนที่**
   สาขาที่ยังไม่มีลิงก์ (00024, 00032–00039, 00042, 00043) ระบบจะลองค้นจากชื่อ "ร้านสมใจ สาขา …" ถ้าหาไม่เจอ ให้ใส่ lat/lng เองในชีต "สาขา"
   **สาขาสายสี่ (00005) ต้องมีพิกัดก่อนทดลอง**
7. ใส่ **วันหยุดบริษัท** ในชีต "วันหยุด"
8. **Deploy**: ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน (monpriya@somjai.co.th)**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน** (Anyone)
   - กด Deploy แล้วคัดลอก URL ไปให้สาขาสายสี่และคลัง
9. ทดลองด้วยตัวเอง: ขอคิว 1 รายการ → เข้า "สำหรับคลัง" ด้วย PIN คลัง → ยืนยัน → เปิดใบงาน → ปิดรอบ

> **ถ้าไม่มีตัวเลือก "ทุกคน" ในข้อ 8** แปลว่าผู้ดูแล Google Workspace ของ somjai.co.th ปิดการแชร์ออกนอกองค์กรไว้
> ทางเลือก: (ก) ให้ผู้ดูแลเปิดสิทธิ์ให้บัญชีนี้ หรือ (ข) เลือก "ทุกคนใน somjai.co.th" — ใช้ได้เฉพาะพนักงานที่มีอีเมล @somjai.co.th และล็อกอิน Google ไว้

### อัปเดตโค้ดภายหลัง

วาง `dist/Code.gs` ฉบับใหม่ทับ (**ใส่ PIN ใน setPins ไม่ต้อง** — PIN เก็บแยกไว้แล้ว) → ทำให้ใช้งานได้ → **จัดการการทำให้ใช้งานได้** → แก้ไข (✎) → เวอร์ชัน: **เวอร์ชันใหม่** → ทำให้ใช้งานได้
(ลิงก์เดิมใช้ต่อได้ ไม่ต้องส่งลิงก์ใหม่)

### ข้อควรรู้

- **ชีตฐานข้อมูล** แชร์เฉพาะผู้ดูแล — คนอื่นใช้ผ่านเว็บเท่านั้น
- **ห้ามสลับลำดับคอลัมน์** ในชีต เพิ่มได้ที่ท้ายตารางเท่านั้น
- **เปิดใช้สาขาเพิ่ม**: ชีต "ตั้งค่า" → `pilotBranches` ใส่รหัสคั่นด้วย `,` หรือเว้นว่าง = ทุกสาขา
- **เปลี่ยนตารางรอบรถ**: เพิ่มแถวชุดใหม่ในชีต "ตารางรอบรถ" พร้อม "เริ่มใช้" — อย่าลบชุดเก่า
- **เปลี่ยน PIN**: รัน `setPins` ใหม่ · ใส่ PIN ผิดเกิน 10 ครั้งใน 15 นาที ระบบล็อกการเข้าส่วนคลัง/อนุมัติ 15 นาที
- **ถ้าบัญชีนี้ถูกปิด** ระบบจะหยุดทำงาน — ก่อนเปลี่ยนเจ้าของ ให้โอนสิทธิ์ชีตและสคริปต์ให้บัญชีใหม่แล้ว Deploy ใหม่

## สำหรับนักพัฒนา

แก้โค้ดที่ `apps-script/` แล้วสร้างไฟล์รวมใหม่ก่อน commit:

```
node truck-queue/tools/bundle.js
node --test truck-queue/tests/*.test.js
```

ทดสอบสูตรค่าส่งกับตัวอย่างทั้ง 6 ข้อในประกาศ COO009/69, ปฏิทินรอบรถ, การกันที่ในรอบ, การอนุมัติ, การปิดรอบ,
การเลื่อนอัตโนมัติ และ PIN — ฝั่งเซิร์ฟเวอร์รันกับชีตและ Maps จำลอง
